## 2. 论文变量与文件的对应

论文没有说明这些，它们是通过寻找能复现论文印刷数字的定义反推出来的。

- **token 比例** = `choice_i / votes_given`，即占*预算*的比例，而不是占实际花出 token 的比例。
  除以实际花出的 token 无法复现 Table 1。
- **`early` = 20/80 权力条件。** 文件 `anonymous_round3_vote.csv` 是论文的第二轮。
- **Table 2 是加性双因素 MANOVA**（`quadratic + same`），尽管正文称之为单因素。正文引用的单独
  单因素结果（例如第一轮 P = 0.0222）同样复现，并因此与 Table 2 略有不同。
- **问卷回归**是对 182 名受访者原始 1–5 分做的单预测变量 OLS。`Q1_1`（"犹豫不决"）、
  `Q1_2`（"不擅长维持秩序"）和 `Q2_10`（"可能产生意外结果"）是反向表述题，因此负系数表示
  评价更正面。正文中的符号与此一致。图 5–6 把这三题反转显示（6 − x）。

## 3. 在论文中发现的不一致（已对照数据验证）

1. **第二轮样本包含 8 行标为 `pilots` 的数据。** Table 1（第二轮）只有包含它们才能复现；去掉后
   所有均值都会改变。论文把第二轮描述为美国的盲测参与者，并提到单独的预实验；文件中的 `phase`
   标签（`pilots` 8、`round-1` 5、`round-2` 17、`round-3` 45）与该描述对不上。
2. **各文件样本量不同。** 投票：177（102 + 75）；治理问卷：182 人；AI 价值问卷：183 人。
   人口统计百分比（如 32.07%、60.33%）对应分母 184，而不是 177。
3. **177 行投票中有 23 行预算没有花完**（第一轮 16 行有剩余，1 行多花一个 token，第二轮 8 行
   pilots 中 6 行有剩余）。由于比例按预算计算，四个比例之和小于 1，这就是 Table 1 均值之和不为
   1 的原因。第二轮花完预算的行中，四个比例之和恒为 1，因此四变量 MANOVA 秩亏；论文第二轮印出的
   自由度 4 取决于那 6 行有剩余的 pilots；去掉 pilots 后 `statsmodels` 给出 3。
4. **Table 1 第二轮：**两个二次投票行选项 4 的标准差都印为 0.201，数据给出 0.209（0.2087 和
   0.2089），因此其中一个印刷值像是转录错误。Table 1 其余条目都吻合。
5. **Table 3 第二轮，投票权力：**正文称投票权力条件"显著影响"结果（Pillai 0.11，P = 0.08）。
   Table 3 给出 P = 0.0806，在 0.05 水平上并不显著。
6. **正文两个问卷均值未复现。**"投票方式有意义"：论文 4.14（SD 0.815），数据 4.17（0.71）。
   "投票方式相关"：论文 4.03（0.92），数据 4.19（0.77）（n = 182）。

## 4. 敏感性分析（论文中没有）

`results/tables/sensitivity_*.csv`，`results/figures/sensitivity_pvalues.png`。

**投票方式**（二次 vs 排序）效应的 p 值，Pillai's trace：

| 数据处理 | 第一轮 | 第二轮 |
|---|---:|---:|
| 论文做法（Table 2） | 0.0233 | 0.3786 |
| 排除 `pilots` 行 | 0.0233 | 0.5195 |
| 仅保留花完预算的行 | 0.1068 | 0.4772 |
| 按实际花出 token 计算比例 | 0.0419 | 0.5171 |
| 论文比例，去掉选项 4（3 个变量） | 0.0117 | 0.3211 |
| 加性对数比（零值 + 0.5 token） | 0.0311 | 0.7602 |
| 置换检验（10,000 次，4 个变量） | 0.0229 | 0.3665 |

当四个比例之和恒为 1 时，代码自动去掉最后一个，因此这些行的自由度为 3。解读：第一轮按投票
方式的差异在多数处理下接近或低于 0.05，但只用花完预算的行时不显著（n = 85）；第二轮任何处理
下投票方式效应都不显著。**投票权力**效应在这些处理下都不显著（最小 p = 0.087，加性对数比，
第一轮）；在 Table 3 的交互模型中，第二轮的值为 0.0806。

其他检查：

- **两轮合并并加入轮次效应**（`sensitivity_pooled_round_effect.csv`）：投票方式 P = 0.0487，
  轮次 P = 0.0262，投票权力 P = 0.4485，交互 P = 0.5444。两轮之间存在差异。
- **多重比较。**问卷回归对 12 个题目做了检验，没有校正。在每个模型和项内做 Holm 校正后，只有
  `Q1_1` 对投票权力（Holm P = 0.0012）和 `Q2_10` 对投票权力（P < 0.001）仍显著。`Q1_2` 对
  投票方式（原始 P = 0.031，Holm 0.37）、`Q1_2` 对投票权力（0.046，Holm 0.46）和 `Q2_5` 对
  投票方式（0.042，Holm 0.46）不显著。
- **各规则会选出什么**（`outcomes_by_condition.csv`）。论文分析的是 token 怎么分配，而不是哪个
  选项胜出。该表按原始 token 数给出胜者，二次投票条件还按每人 token 的平方根给出胜者。它假设所有
  条件下 `choice_i` 列都是 token 数，数据并未说明；请视为探索性结果。

## 5. 论文设计所能说明的限度

- token 比例描述的是人们在各规则下如何花预算。它们本身并不能证明二次投票提高了少数群体的影响力，
  而且没有"一人一票"条件可供比较。
- 群体归属（全球南方、视障等）不在公开文件中，因此无法按群体分析。

## 6. 无法用公开文件复现的部分

- **V-Dem 子量表（图 7）：只能部分复现。**题目映射不在文件中。把题目按连续块划分（`vdem.py`）
  可以复现图 7 的全部 40 根柱和 7 个引用回归中的 5 个，但这是推断的；Political Equality 的
  p 值和 Deliberative 交互项没有复现。见 `docs/FIGURE_COMPARISON.zh-CN.md` 第 4 节。
- **图 8 相关矩阵：**未复现。两份问卷没有参与者 ID，行也对不上；诊断见
  `FIGURE_COMPARISON.zh-CN.md` 第 8 节。
- **图 3：**满意度陈述不在公开文件中；只能按论文数值重绘（该文档第 7 节）。
- **图 9 聚类**使用 OpenAI Ada-2 嵌入，离线不可用。`fig9.py` 中有替代版本（spaCy 词向量），
  其结果强烈依赖嵌入方式，不是复现（该文档第 9 节）。早先的 TF-IDF 版本被替换，因为 k-means
  只分出一组组完全相同的短消息。论文还说 elbow 方法"最大化"簇内平方和；elbow 准则找的是它
  不再快速下降的位置。
- **招募和平台细节**（滚雪球、Facebook、私信，以及后来的 Prolific）无法重跑。
